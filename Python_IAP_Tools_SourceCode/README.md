#IAP-Tools for Python

#### 介绍

1.  Python_IAP_Tools_SourceCode包含Python工程和PAGE GUI工程。
    The ‌Python_IAP_Tools_SourceCode‌ host computer includes both a ‌Python project‌ and a ‌PAGE GUI project‌.

2.  GUI界面工程在PAGE_GUI_Project里面，使用Python开源的tkinter，GUI界面使用PAGE绘制。
    The ‌GUI interface project‌ is located in PAGE_GUI_Project‌, which uses ‌Python's open-source tkinter‌ for GUI development. The GUI interface is designed using ‌PAGE (Python GUI Designer)‌.

3.  IAP_tools_Python_Project 使用Python 3.13.3,可以根据requirements.txt安装依赖库，直接运行build_exe.bat就会自动调用pyinstaller打包成exe。
    The ‌IAP_tools_Python_Project‌ is developed with ‌Python 3.13.3‌. You can install the required dependencies via ‌requirements.txt‌. Simply running ‌build_exe.bat‌ will automatically invoke ‌pyinstaller‌ to package the project into an ‌executable (exe)‌.
